## 🌟 Overview

**SkillPulse** is a full-stack, AI-powered mock interview ecosystem designed to bridge the gap between job seekers and real-world hiring standards. Built using the **MERN stack (MongoDB, Express, React, Node.js)**, it simulates rigorous interview environments with advanced features tailored to modern tech recruitment. SkillPulse acts as an intelligent agent, assessing technical depth, communication clarity, and overall candidate confidence.

---

## ✨ Key Features & Integration

- **🤖 AI Interview Agent:** Simulates real-time conversational interviews with dynamic question generation and AI-driven follow-up scenarios.
- **📄 Smart Resume Upload & Parsing:** Parses uploaded resumes to tailor interview questions specifically to the candidate's project history, skills, and experience.
- **🛠️ Role & Experience Selection:** Dynamically adjusts difficulty and question banks based on the target job profile and seniority level.
- **🎙️ Smart Voice & Audio Interaction:** Real-time conversational flow with speech simulation, voice analysis, and immediate feedback.
- **⏱️ Timed Simulations:** Recreates high-pressure interview environments with strict time-tracking constraints.
- **📊 AI Answer Evaluation:** Comprehensive scoring metrics analyzing communication clarity, technical accuracy, and confidence levels.
- **📑 Downloadable PDF Reports:** Generates granular evaluation reports detailing strengths, weaknesses, and actionable insights.
- **📈 History & Analytics Dashboard:** Tracks long-term progression through graphical trends and historical logs.
- **💳 Razorpay Payment Integration:** Integrated secure payment processing for purchasing credits and unlocking premium interview features.
- **🚀 Deployment:** Fully deployed and optimized for production on Vercel.

---

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS, Redux, Motion (Framer Motion), React Icons
- **Backend:** Node.js, Express, Database Integration
- **Database:** MongoDB
- **AI Integration:** AI Question Generation & Evaluation Models
- **Payment Gateway:** Razorpay
- **Deployment:** Vercel
